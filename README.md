# 校園傳說 Online 2D（v0.8.0 GBC 像素可玩原型）

原創校園題材 2D 網頁 RPG，採用經典 Game Boy Color 時代的俯視角像素美術方向。遊戲使用原創像素繪圖與角色設計，不包含《亂 Online》原作模型、貼圖、程式或商標素材。

## v0.7.0 更新
- 將原本的 3D Three.js 測試畫面改為 2D Canvas 像素遊戲。
- 經典 GBC 風格：俯視角、像素化地圖、校園建築、樹木、道路及角色。
- Android 手機左下角類比虛擬搖桿（可拖曳控制方向與移動速度），右下角攻擊、技能、恢復、拾取按鈕。
- 男女角色選擇，四大職業：劍道部、格鬥部、弓箭部、氣功部。
- 近戰／遠程攻擊、訓練假人、HP／MP／EXP、升級、金幣與新生任務。
- localStorage 儲存等級、經驗、金幣及任務進度。
- 保留 Express 與 Socket.IO；伺服器啟動時可同步在線玩家位置與戰鬥事件，伺服器未啟動仍可單人遊玩。
- 本版人物與地圖使用原創 Canvas 像素繪製，不依賴外部模型下載。

## 執行方式
需要 Node.js 18 或更新版本。在專案根目錄執行：

```bash
npm install
npm start
```

開啟 StackBlitz 的 Web Preview，或在瀏覽器開啟本機伺服器網址。

## Android 手機測試
1. 開啟 https://stackblitz.com/github/carmenykm/campus-legend-online
2. 等待專案載入後執行 `npm start`。
3. 開啟 Web Preview。
4. 選擇角色性別與職業，按「進入學園」。
5. 使用畫面左下角虛擬搖桿拖曳移動，右下角按鈕攻擊、放技能、恢復及拾取。

若 StackBlitz 手機瀏覽器記憶體不足，可先關閉其他分頁再重新開啟 Preview。

## 操作
- 電腦：WASD／方向鍵移動、J 攻擊、K 技能、E 拾取。
- 手機：按住並拖曳左下角虛擬搖桿控制方向與速度；右下功能按鈕操作。

## 目前版本範圍與限制
- v0.7.0 是可遊玩的單機核心原型，並非完整 MMORPG。
- Socket.IO 目前同步在線玩家位置與戰鬥事件；怪物狀態、戰鬥結果、掉落及角色存檔尚未由伺服器權威管理。
- 地圖、角色、怪物和動畫目前以程式繪製，後續可逐步替換為更細緻、具方向及動作影格的原創像素素材。
- 四大職業已有不同基礎數值、攻擊距離及技能名稱；專屬技能動畫、裝備系統、完整任務與地圖傳送仍待開發。
