# 校園傳說 Online（v0.3 角色重製測試版）

這是原創的校園 MMORPG 網頁原型，以經典校園 MMORPG 的年代感與職業辨識度作為方向；不包含《亂Online》的原始模型、貼圖、程式或商標素材。

## v0.3 更新
- 四大職業：劍道部、格鬥部、弓箭部、氣功部。
- 校園制服風格的程序化 3D 人形角色與職業裝備。
- 基礎走路、普通攻擊動作。
- 校園場景、戰鬥、升級、手機方向控制。
- Socket.IO 在線玩家名單與位置同步（原型功能）。

## 執行
需要 Node.js 18 或更新版本。在專案根目錄執行：

```bash
npm install
npm start
```

開啟 StackBlitz 提供的 Web Preview。

## 注意
角色仍為程序化 3D 幾何模型，不是《亂Online》原版高精度模型或官方素材。多人同步目前只包含在線名單與位置；戰鬥、怪物、掉落、存檔仍在用戶端模擬，尚未達正式 MMORPG 伺服器規格。Three.js 與 Socket.IO 瀏覽器模組由 CDN 載入，首次遊玩需要網路。
