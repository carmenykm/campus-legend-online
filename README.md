# 校園傳說 Online（v0.5.1 初始校服模組）

原創校園 MMORPG 網頁原型，參考《亂 Online》官方公開的校園制服與遊戲設定，重新設計原創人物；不包含原作模型、貼圖、程式或商標素材。

## v0.5.1 更新
- 初始角色統一採用經典校園制服方向：白色短袖襯衫、深色領帶、深藍長褲／百褶裙、深色鞋子。
- 加入襯衫領片、門襟鈕扣、胸前口袋、學院徽章、腰帶等細節。
- 女性角色採裙裝與長髮；男性角色採長褲造型。
- 四大職業顏色收斂為小型胸章識別，不再大面積改變基本校服。
- 保留四大職業的武器識別、男女選擇、第三人稱鏡頭及既有基本玩法。

## 執行
需要 Node.js 18 或更新版本。在專案根目錄執行：

```bash
npm install
npm start
```

開啟 StackBlitz 提供的 Web Preview。

## 目前限制
- 目前校服與人物仍由 Three.js 程序化幾何組成，是初始外觀模組，不是完成的高精度原作級模型。
- 尚未使用專業雕刻／拓樸製作的高精度角色網格、正式骨架蒙皮或動作捕捉動畫。
- 後續需要以實際 Android 測試確認比例、衣服穿插、裙褲細節及效能，再進一步製作正式 GLB/GLTF 模型。
- 多人同步目前只包含在線名單與位置；戰鬥、怪物、掉落、存檔仍在用戶端模擬，尚未達正式 MMORPG 伺服器規格。
- Three.js 與 Socket.IO 瀏覽器模組由 CDN 載入，首次遊玩需要網路。
