# 校園傳說 Online（v0.4 人物外觀改良版）

原創校園 MMORPG 網頁原型，以經典校園 MMORPG 的年代感與職業辨識度作為方向；不包含《亂Online》的原始模型、貼圖、程式或商標素材。

## v0.4 更新
- 角色建立畫面新增男性／女性選擇。
- 四大職業均可選擇男女角色，共八種職業性別組合。
- 改良頭部、五官、髮型、肩膀、軀幹及四肢的程序化 3D 外觀。
- 女性角色採裙裝及較長髮型；男性角色採長褲造型。
- 保留四大職業的武器、配色與基本走路／攻擊動作。
- 多人在線玩家資料同步性別，遠端角色會依性別顯示。

## 執行
需要 Node.js 18 或更新版本。在專案根目錄執行：

```bash
npm install
npm start
```

開啟 StackBlitz 提供的 Web Preview。

## 目前限制
- 角色目前仍是 Three.js 程序化幾何模型，尚未使用專業雕刻／拓樸製作的高精度角色網格、正式骨架蒙皮或動作捕捉動畫。
- 男女外觀是第一輪基礎區分，髮型、臉型、服裝細節與身形仍待深化。
- 多人同步目前只包含在線名單與位置；戰鬥、怪物、掉落、存檔仍在用戶端模擬，尚未達正式 MMORPG 伺服器規格。
- Three.js 與 Socket.IO 瀏覽器模組由 CDN 載入，首次遊玩需要網路。
